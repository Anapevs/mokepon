# **Mokepon - Multiplayer Game🔥**

A multiplayer monster-battle game where players choose a Mokepon, move on a map, and engage in strategic turn-based combat. Built using **JavaScript, HTML5 Canvas, and Fetch API** for online battles. This was developed during a Basic Programming Course.

**📂 Project Structure**
```
/mokepon
│── /public/
│ ├── index.html # Main game page
│ ├── styles.css # styles
│ ├── /js/
│ │ ├── mokepon.js # Game logic
│ ├── /assets/ # Images
│── index.js # Backend server (Node.js + Express)
│── package.json # Node.js dependencies
│── package-lock.json # Dependency lock file
│── .gitignore 
│── README.md 
```
- **Real-Time Multiplayer**: Uses **Node.js** for player interactions.
- **Turn-Based Combat**: Attack enemies using Fire 🔥, Water 💧, and Earth 🌱.
- **Canvas-Based Map**: Players move on a dynamic game world.
- **Express.js Backend**: Manages player connections and game state.
- **REST API Integration**: Backend communicates with the frontend using Fetch API.
